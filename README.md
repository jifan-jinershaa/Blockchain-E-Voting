🗳️ Blockchain E-Voting System

A modern and secure Electronic Voting System prototype designed to demonstrate a digital voting workflow with a professional, government-inspired user interface.

The project focuses on creating a simple, transparent, and user-friendly voting experience — from authentication and candidate selection to vote confirmation and results visualization.


🚀 Project Overview

The Blockchain E-Voting System is a web-based voting platform prototype that demonstrates how a digital election system can be designed for secure and accessible voting.

The application provides a structured voting workflow:

```text
User Registration / Login
        ↓
Voting Dashboard
        ↓
Candidate Selection
        ↓
Vote Review
        ↓
Confirm & Cast Vote
        ↓
Live Results Dashboard
```

Once a vote is cast, the user is taken away from the candidate-selection flow and redirected to the results/dashboard experience.

🔄 Voting Process

1. Login / Registration

The user enters the voting system through the authentication interface.

2. Candidate Selection

The voter can browse the available candidates and select their preferred candidate.

3. Vote Review

Before submitting, the voter can review their selected candidate.

4. Vote Casting

The voter confirms the selection and casts the vote.

5. Results Dashboard

After casting the vote, the user is redirected to the results/dashboard rather than being allowed to repeat the candidate-selection process.


🎯 Project Objectives

⚠️ Prototype Disclaimer

This project is currently a demonstration prototype.

The deployed version is intended to demonstrate the application's user interface, voting workflow, navigation, and results experience. Production deployment would require a secure backend, database, identity verification, cryptographic security, blockchain infrastructure, and comprehensive security auditing.
