# BHARAT E-VOTE

An academic, full-stack electronic voting prototype built with React, Vite, Express, JSON persistence, and an educational blockchain simulation.

## Run locally

```bash
npm install
npm run dev
```

The Vite development server mounts the Express API at `/api`. For a production-style run:

```bash
npm run build
npm start
```
